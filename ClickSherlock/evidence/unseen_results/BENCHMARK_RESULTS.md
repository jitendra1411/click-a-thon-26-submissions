## What the unseen day stress-tested

1. Schema evolution: `video_resolution` + `show_name` flowed raw → enriched
   with zero code changes (nullable columns, MV passthrough/dict).
2. Variable-length IDs: switched to `String` (not `FixedString(64)`) — the
   file's IDs load unchanged.
3. 7M-event scale: day-scoped load + MV enrichment in ~16 s; the bootstrap
   state machine over 2.9M enriched events in < 1 s; serving stays
   sub-second to tens-of-ms.

## Notes / known nuances

- The raw file contains **garbage timestamps spanning 2014-2026**; the load
  is scoped to the unseen day (`--load-raw FILE 2026-07-31`) — other-day rows
  are ignored by design.
- Sessions crossing midnight fan minute facts into 08-01 (the liveness tail
  extends past 00:00 IST); day-scoped queries include those tail minutes.
- `pipeline_runs` was not populated by the manual bootstrap invocation (the
  live refresh loop writes it); a `--loop` cycle records it automatically.
